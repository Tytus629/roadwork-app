## C) Items You Must Supply Manually

### 1. GoogleService-Info.plist (BLOCKER)

- Download from [Firebase Console](https://console.firebase.google.com) → Project Settings → iOS app
- If no iOS app is registered yet, add one with bundle ID `com.roadworktracker.app` (or your chosen ID)
- Place at `ios/RoadWorkTracker/GoogleService-Info.plist`
- Add to Xcode project (drag into RoadWorkTracker group, check "Copy items")

### 2. Google Maps API key for iOS (BLOCKER for maps)

- Go to Google Cloud Console → APIs & Services → Credentials
- Create or reuse an API key restricted to "Maps SDK for iOS"
- Add to `AppDelegate.swift` before `FirebaseApp.configure()`:

```swift
import GoogleMaps
// ...
GMSServices.provideAPIKey("YOUR_IOS_MAPS_API_KEY")
```

### 3. Bundle Identifier (BLOCKER for device/TestFlight)

- Current: `org.reactjs.native.example.RoadWorkTracker` (RN template default)
- Change to your production ID (e.g., `com.roadworktracker.app`) in both Debug and Release build settings
- Must match the bundle ID registered in your Apple Developer account and Firebase iOS app

### 4. Apple Developer Team / Signing (BLOCKER for device/TestFlight)

- Requires a paid Apple Developer account ($99/year)
- In Xcode: target → Signing & Capabilities → set Team
- Or add `DEVELOPMENT_TEAM = YOUR_TEAM_ID;` to both build configurations in pbxproj
- For TestFlight: must use "Apple Distribution" signing identity + provisioning profile

### 5. App Icon Images

- AppIcon.appiconset has 7 size slots defined but no actual image files
- Provide a 1024×1024 source PNG
- Generate all sizes using AppIcon Generator or Xcode's asset catalog

## E) Step-by-Step: First iPhone Test Build

### Prerequisites

- macOS with Xcode 15+ installed
- Apple Developer account (paid)
- Node.js, Ruby, CocoaPods installed on Mac

### Steps

#### 1. Configure Firebase iOS app

```text
# In Firebase Console:
# - Add iOS app with your chosen bundle ID
# - Download GoogleService-Info.plist
# - Copy to ios/RoadWorkTracker/
# - Add to Xcode project
```

#### 2. Set bundle ID

```text
# In Xcode, open ios/RoadWorkTracker.xcodeproj
# Target → General → Bundle Identifier → set to your ID (e.g., com.roadworktracker.app)
# Or search-replace in project.pbxproj:
#   "org.reactjs.native.example.$(PRODUCT_NAME:rfc1034identifier)"
#   → "com.roadworktracker.app"
```

#### 3. Add Google Maps API key

```swift
// In ios/RoadWorkTracker/AppDelegate.swift, add before FirebaseApp.configure():
import GoogleMaps
// Then in didFinishLaunchingWithOptions:
GMSServices.provideAPIKey("YOUR_IOS_MAPS_KEY")
```

#### 4. Install pods

```bash
cd ios
bundle install          # install CocoaPods from Gemfile
bundle exec pod install # resolve all native dependencies
cd ..
```

#### 5. Set signing

```text
# In Xcode:
# - Open ios/RoadWorkTracker.xcworkspace (NOT .xcodeproj)
# - Target → Signing & Capabilities
# - Select your Team
# - Ensure "Automatically manage signing" is checked
```

#### 6. Add app icons

```text
# Provide 1024x1024 PNG
# Use Xcode Asset Catalog or generator tool to fill all slots
```

#### 7. Build for simulator (smoke test)

```bash
npx react-native run-ios --simulator="iPhone 16"
```

#### 8. Build for device

```bash
npx react-native run-ios --device "Your iPhone"
```

#### 9. Archive for TestFlight

```text
# In Xcode:
# - Product → Archive
# - Wait for build
# - Organizer → Distribute App → App Store Connect → Upload
# - In App Store Connect: enable TestFlight testing, add testers
```

#### 10. Post-upload

- Change entitlements `aps-environment` from `development` to `production` for App Store builds
- Verify Crashlytics dSYMs appeared in Firebase Console after first TestFlight build
